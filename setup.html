CODE-FORGE

配置并启动对抗回环

填完点 Run 就开跑:后台起一个 Claude Code(claude -p)当执行者, 用你自己的订阅 —— 不需要任何 API key。达标与否由代码跑判据裁定,不问模型。

目标 判据由代码跑

一句话说清要做什么,再给一条能跑的命令当判据:退出码 0 且(可选)指标落进区间 = 达标,立刻停。 判据留空也能跑,但那次回环判不出达标,只能靠轮数/时限停 —— 页面会如实标「未判定」。

限制 硬闸

到顶就停,页面会写清是哪一条停的。宿主执行时 token 在你订阅账上、数不到,所以这里只有轮数与时间。

角色 各绑不同模型

按这个顺序发言。反驳者派给 forge-critic —— 它在工具层面就没有写权限, 一个能顺手把问题抹平的反驳者等于没有反驳者。

权限 agent 能动到什么

它要改文件、跑测试才干得成活。这一栏决定它需不需要有人点确认 —— 无人值守就得放开,请按仓库可信度选。
